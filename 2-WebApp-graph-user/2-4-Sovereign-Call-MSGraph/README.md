# Microsoft Graph in national clouds

The standalone national-cloud application has been retired. Use the
[standard Microsoft Graph sample](../2-1-Call-MSGraph/README.md) with the
[national-cloud configuration guide](../../1-WebApp-OIDC/1-4-Sovereign/README.md#microsoft-graph).

This documentation-only entry point preserves existing chapter links. The guide
covers cloud-specific app registration, authority, Graph endpoints, and scopes;
removing the separate application does not change SDK support for national clouds.
